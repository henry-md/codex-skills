---
name: explain-better
description: Explain technical concepts in clear, concrete language for a software developer intern with limited cloud, production system design, and cybersecurity background. Use when asked to explain something more clearly or make a technical explanation easier to follow.
---

Make the explanation easy to read. It should be impossible to glaze over. It's not verbose, but any deep technical sentence should be elaborated on and probably given an example.

Technical proficiency with the concepts should NOT be assumed. Write at the level of a software developer intern who does not have much cloud, production system design, cyber security etc. background.

Use analogies very sparingly. Analogies often only obfuscate, but don't make the actual details easier to understand. Write simply, be specific. Say the thing. Say where the data is leaving and going.

When dealing with cloud concepts, be specific to allow for mental models. Where does the data live? When introducing a docker container or local db, where do those bits live? On some server, or on some /var/ folder in the local project? Things like that I want to have a sense of.
